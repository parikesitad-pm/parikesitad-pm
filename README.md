### 🦉 Owl · Dap's AI

**[Ask Owl anything about me ↗](https://d-ap.my.id/ask)** — a thinking companion, not an oracle.

Owl answers only from my CV and my site, and shows which files each answer came from. If it is not on record, it says so.

- **How it works:** question → embed (Gemini) → top 5 matching chunks → grounded answer → stream, with sources under every answer
- **Three providers, one reply:** Gemini first, then Groq, then Mistral on a 429 or outage; keyword search when every model is out
- **Tested:** a fixed eval set for retrieval and a separate one for routing questions about me, dev help and off-topic prompts
- **Born in [Forge](https://github.com/parikesitad-pm/forge)**, with one rule carried over: *the Owl observes, the thinker decides.*

Full write-up: [ask-dap case study ↗](https://d-ap.my.id/cases/ask-dap)
